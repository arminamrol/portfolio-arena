# Code is MIT; the resume content is not

The repository is public so anyone can read how it is built, and forking it is welcome. The code is licensed under MIT. The Resume Data (`src/resume/resumeData.ts`) is the Owner's personal resume and is excluded: it is all rights reserved. A fork is expected to replace it with its own Owner's resume before deploying. Without the exclusion, MIT would let anyone redeploy the site as-is, under the Owner's name.

## Considered Options

- **The whole repository under MIT**: simplest, but grants the right to republish the Owner's identity and work history.
- **No license (visible only)**: protects the content, but makes the code unusable by anyone, which defeats the point of opening it.
